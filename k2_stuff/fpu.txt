 New Float Block Register Definitions 

Base Address: $DE80

$DE80: Control Register0
Bit[0] = MUXA Ctrl -> 1'b0 = User Input0, 1'b1 = Converted User Input0 (Fixed [20:12] -> Float 32bits)
Bit[1] = MUXB Ctrl -> 1'b0 = User Input1, 1'b1 = Converted User Input1 (Fixed [20:12] -> Float 32bits)
Bit[2] = Not Used
Bit[3] = Addition Block TValid**
Bit[5:4] = MUX C Ctrl
2'b00: Output of MUXA
2'b01: Output of MUXB
2'b10: Mutiplier Output
2'b11: Divier Output
Bit[7:6] = Mux D Ctrl
2'b00: Output of MUXA
2'b01: Output of MUXB
2'b10: Multiplier Output
2'b11: Divider Output

$DE81: Control Register1
Bit[1:0]: MUXE Ctrl
2'b00: Multiplier Output
2'b01: Divider Output
2'b10: Adder Output
2'b11: Float Value of 0 (0x3F80_0000)

$DE82: Control Register2
Bit[0]: Converter 0 TValid
Bit[1]:  Input0 TValid
Bit[2]: Converter 1 TValid
Bit[3]: Input1 TValid

$DE83: Not Used

TValid Control Register
FP_MATH_CTRL2[0] = Converter_20I12F_2_FP Block 0 - TVALID
FP_MATH_CTRL2[1] = User Input 0 - TVALID
FP_MATH_CTRL2[2] = Converter_20I12F_2_FP Block 1 - TVALID
FP_MATH_CTRL2[3] = User Input 1 - TVALID
 
So, bottom line, after you set your User Input 0 and User Input 1 and you have chosen your path for computation, then you need to set the TVALID Flag in Control Register 2 [1] & Control Register 2 [2]...

This is will let the FP block that the data is valid and that very bit will be used to carry around the validity of the results.
Then you just have to wait for the Status Register TValid bit of the block you want to know when the output is valid, So to make it really efficient then you could either keep it 1 and then count the number of clocks (or instructions) you have to wait to get a valid Tvalid and then when you know, it is always the same, you don't have to poll the TValid you just know...
Each Block have latency, so having different route of calculation will make it tricky to know all the different combination
